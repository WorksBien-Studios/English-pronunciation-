# Trademark search — status and worksheet

**Date:** 2026-09-29  
**Status:** creature names resolved by using generic names; app name and concept name **not yet searched**.  
**Not legal advice.**

## Decision

Creature names are generic sound labels — **Rくん, Lくん, THくん, Vくん, Fくん, Bくん** — and the guide is called コーチ (a common role word). Names that only state the sound or role are descriptive and cannot be owned as a brand, so they need no clearance. This replaces the earlier onomatopoeic names (くるりん, くるん, ぺろ, べー, がぶ, はむ, ふーふー, ぷっぷ).

The **artwork** is a separate matter: see [`character-similarity-screen.md`](character-similarity-screen.md). Final illustrator art should be re-screened.

## What was attempted for the old names

The official databases could not be queried from the build environment: J-PlatPat and the WIPO Global Brand Database are blocked by the egress proxy (and are interactive JavaScript apps); USPTO and EUIPO were not attempted for the same reason. Web searches turned up no exact character matches for the onomatopoeic names, which proves nothing about registered marks.
