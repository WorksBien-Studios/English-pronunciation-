# UI mockup source

Design-canvas artboards (`*.dc.html`) and layout (`canvas.json`) for the 音の島 concept described in
[`docs/game-ui-concept.md`](../../docs/game-ui-concept.md).

- Files are authored for the Claude Design canvas runtime (`<x-dc>` components, `support.js`), which is not
  included here; they are not standalone web pages.
- `Creature`, `Coach`, `MouthDiagram`, `PhoneTabs` and `PadTabs` are shared components imported by the screens.
- All art is original vector artwork drawn for this project.
